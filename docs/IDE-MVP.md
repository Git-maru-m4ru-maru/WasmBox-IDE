# WasmBox IDE MVP

WasmBox IDEは、既存のWasmBox仮想Linuxを再利用するブラウザ内IDEです。専用のユーザー実行サーバーを用意せず、ブラウザ内で編集・保存し、仮想Linuxでコードを実行します。

## 初期機能

- ファイル一覧、行番号付きのコード編集、新規ファイル作成
- IndexedDBへの自動保存
- JSON形式のプロジェクト読み込み・書き出し
- Python、Node.js、Shellスクリプトの実行
- ファイル名・サイズ・プロジェクト容量の検証
- Linux仮想ディスクの保存は既存WasmBoxの仕組みを利用

プロジェクトは最大30ファイル、1ファイル32 KiB、合計64 KiBです。保存は現在のブラウザ内のみです。別の端末との同期やアカウント連携は含みません。

## 開発・検証

開発環境では npm install のあと、npm run typecheck、npm test、npm run site:build を実行します。ビルド済みサイトでは /ide.html を開きます。Linuxイメージとv86のファイルは、従来のWasmBoxサイトと同じアセットを利用します。

実ブラウザでのエディタからLinuxまでの結合検証は、コミット時点で未実施です。初回起動の時間、ターミナル入力、実行停止、出力抽出について、利用するブラウザで確認が必要です。
